# 把公开示例接到系统

## 这个仓库能直接运行哪些部分

`demo/read_exam.py` 负责验证输入文件、检查时间与截止轮、导出单题允许的历史。测试完全离线，不需要账号。

当前未提供可以一键跑通每个社区项目的完整适配器。下面是接入必须保持的边界和步骤；各项目自身的启动方式以固定版本上游说明为准。不要把完成输入校验理解为已经验证真实模型调用或系统效果。

## 读取一题

```python
from demo.read_exam import get_question

item = get_question("PUB01-C001/d45")
print(item["id"], item["now"], item["cutoff_turn"])
```

`item["history"]` 每轮含 `轮次`、`逻辑时间`、`用户消息`、`助手回复`、`日`。历史是原生记忆流程的输入，不是最终作答时附带的完整上下文。

## 原生接入顺序

以下是流程示意，不是本仓库已实现的第三方 API：

```text
为该题准备一个独立、空的系统工作目录
for 每个允许读取的历史回合:
    把逻辑时间推进到该回合时间
    用系统原生流程写入该回合的用户消息和已有助手回复
    执行该系统按既定配置应当发生的原生维护
把逻辑时间推进到考试时间，完成应当触发的维护
从记忆快照启动独立考试会话
只按声明的短期窗口附带近期回合
调用原生问答入口，保存真正发送给用户的回答
关闭考试副本；考试内容不得污染其他题的状态
```

允许复用严格对应同一历史前缀的只读快照，以减少重复处理；每题的可写副本必须隔离。不可提前喂入后面的历史，不可把标准答案、人物设定或考点提示作为补充记忆。简单清空 prompt 不一定足够，还要检查系统是否自动从旧会话文件载入全历史。

如果系统只提供记忆检索而不是完整聊天宿主，应记录其输出如何交给统一作答模型。完整聊天系统则用自己的问答编排，不为它额外选取正确证据。

## 应当保存的运行记录

至少记录：仓库 URL 和 commit、适配器版本、模型标识、历史 SHA、题号、截止轮、逻辑时间、短期窗口、实际读取的快照、维护开关与执行次数、最终回答、是否中断。改过归档阈值或窗口，要分阶段记录。

记录模型真实请求的输入边界可以帮助排查作弊式全上下文泄漏，但原始请求可能包含敏感数据。自己的实验日志先留在本地，公开前单独检查；不要提交凭据。

调用失败、没有向用户发送回复、以及语义答错是三种不同情况。不要把内部思考内容当成用户可见回答，也不要用重试刷出一个正确答案。

## 判卷与记忆输入分开

只有判卷环节读取 `demo/review-only/answer-key.jsonl`。其中的 `reference_answer` 是作者写的示例，不是某个系统的真实输出；`required` 和 `forbidden` 才是判据，不应用简单字符串相等来代替语义核对。

本仓库不自带收费判分服务，也不会自动调用模型。请将自己的运行产物放在忽略追踪的 `outputs/` 中，并明确将示例集成绩标为“公开示例上的结果”。
