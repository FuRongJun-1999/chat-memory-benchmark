# 测什么，怎么测

## 场景和统计单位

以长期、低频的个人聊天为目标：每天约两轮，历史跨度最长半年。一轮是一次用户消息加助手回复，不是一个 token，也不是一天。

正式评测使用固定六人物；公开包另写了一个人物，用于解释方法，二者不是同一份卷。正式卷曾经历修订，不同版本的分数不可混在一起比较。当前公开汇总对应 2026-11-01 的冻结版本。

公开示例有 27 个独立事实组，每组四个时间档，共 108 个问题实例。事实组重复提问会相关，不能当成 108 个独立样本。正式卷的细项标签也会重叠，同一题可以考多个能力，因此不能把各考点题数相加当总题数。

## 历史怎么进入系统

1. 冻结历史、题目、判据和版本，保留文件校验值。
2. 按逻辑时间把已有用户消息和已有助手回复送进原生记忆流程，不让模型重写过去的聊天。
3. 按系统实际机制执行需要的整理、归档或衰减；如果需要模型调用，使用真实调用，不能拿固定回复冒充维护结果。
4. 到题目规定的时间，使用截止点之前的记忆答题，不读取未来对话；考试题和考试回答不写入下一题的历史。可以增量复用历史，不要求逐截点复制记忆库。
5. 在原生问答入口答题；更早的聊天由原生记忆投影或实际召回提供，不外挂另一套检索来补答案。

直接短期上下文和持久记忆分开记录。本轮 Soul、ROFM 和 Qwen 对照最多直接提供最近六个完整回合；SurfCore 按其原生记忆卡和会话机制处理，接入差异见配置说明。短期窗口里已有答案的题，不可一概宣称证明了长期记忆。

“经过了几天”使用测试进程里的逻辑时间，不修改整台电脑时钟。只推进时间不等于跑过 Dream 或整理，必须记录维护函数是否真正执行。

## 时间怎么计算

每个考点穿插当天、3 天、15 天、45 天提问。从**评分所需事实的最后一次提及**开始算，用户和助手的复述都算提及；不是简单从首次出现或聊天开始算。

公开示例的当天是最后提及后一秒。多事实题逐项记录时间锚，以最近的评分事实计算题组间隔。过去的计划和限制按当时语境问，不假定 45 天后仍然有效。

## 考点怎么读

| 考点 | 要检查什么 |
| --- | --- |
| 用户的基本信息 | 记住用户自己明确说过的信息 |
| 生日 | 日期能否记对，不擅自编出没有依据的年份 |
| 职业 | 工作信息是否混淆或过时 |
| 偏好 | 喜欢什么，不把一次选择变成永久偏好 |
| 称呼条件 | 在约定的对象、场合下使用称呼 |
| 带条件或期限的偏好和边界 | 记住限制适用的条件和期限 |
| 约定和欠账 | 谁答应了什么、欠谁什么、是否已经完成 |
| 没说完要跟进的事 | 记住待办，未知结果不编造 |
| 真实变化 | 事实发生变化后使用新信息 |
| 改口 | 用户改了主意后不继续用旧安排 |
| 纠错 | 用户明确纠正错误后采纳正确说法 |
| 没解释的矛盾 | 同时保留冲突，不擅自编原因 |
| 相似事件 | 区分相近的人、地点、时间或物件 |
| 第三方事实 | 别人的事情不记到用户头上 |
| 助手自己说过的话 | 区分助手建议和用户承诺 |
| 分散的线索 | 把不同轮次的必要信息组合起来 |
| 时间约定 | 记住约定的时间，不混淆上午下午 |
| 相对日期 | 用当时的日期理解“昨天”“下周”等 |
| 时间题 | 对时长、先后和日期关系作出有依据的回答 |
| 计划假设梦转述猜测 | 区分已发生事实和不同性质的叙述 |
| 计划 | 不把打算当成已经做完 |
| 假设 | 保留“如果”的前提 |
| 转述 | 保留消息来源，不改成亲身经历 |
| 共同编的故事 | 虚构情节不当成现实生活 |
| 资料不足 | 不知道的部分明确留空，不编答案 |
| 敏感的事 | 记住信息的使用限制，不泄露不该说的事 |
| 边界 | 在明确边界内回答与行动 |

## 怎么判分

先检查题目和历史证据，再核对真实系统回答。满足全部必需条件、且没有禁止错误，才算通过。合理的同义表达接受，不要求逐字匹配参考答案；不评表达风格。

- **通过题数 / 已答有效题数**：分母同时显示，避免只有百分比。
- **忘记**：历史有证据但回答遗漏；与胡编分开。
- **认错人、认错事**：把他人经历、另一事件或助手的话记到错误主体上。
- **错误否认**：明明说过却否认说过。
- **编造**：没有证据的日期、原因或结果被当成事实。
- **违反边界、泄露私事**：违反该题明确的限制，而不是笼统地以“说得多”扣分。

相关错误指标只在适用题目上解释；不能因为多数题没有机会触发某类错误，就宣称系统擅长该能力。公开示例的 `retrieval_required: false` 表示部分题可能凭常识答对，也需单列解释。

对于真实中断，记“未答 / 中断”，不伪造答案，也不直接判语义失败。比较多个系统时使用**相同题号的共同已答集合**，并保留各自完成量。缺题后某个考点时间格不足十组，要如实显示。

## 结论能覆盖到哪里

结论只覆盖已测版本、输入和配置。超轻度单人场景的结果不能推广为所有记忆系统或所有负载的总排名；公开小示例也不能作为正式成绩。

本轮原始逐题判卷和完整正式卷尚未公开。公开汇总和 SHA 方便标记版本，但 SHA 本身不能让外部读者核实未公开内容，也不是独立审计证明。
