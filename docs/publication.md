# 这次公开多少

## 已公开

- 测试场景、时间计算、评分原则、失败与中断的处理规则。
- 独立虚构的一个人物：完整历史、题目、答案、证据、可离线浏览的页面。
- 可运行的读题和输入校验代码，以及自动检查。
- 原生接入协议、三个项目的上游版本与配置差异。
- 正式实验的整体、考点、时间格汇总；不包含逐人资料和原始聊天。

## 这次保留

正式六人物考卷、其历史与标准答案、未来未曝光题、原始用户资料、完整请求日志、账户和密钥。不把私有工作目录及其 Git 历史复制到公开仓库。

当前发布不含完整私有实验调度器或各项目的一键适配器；公开代码的验证范围是示例读取及输入边界。正式成绩暂时不能被外部读者完全重算，这个限制不会用“代码开源”或文件 SHA 掩盖。

## 示例如此使用

这个示例包专门重新创作。人物、生活事件、对话、问题和答案全部虚构，由 GPT-6.1 Terra 生成并经过本地复核和结构检查；没有使用正式人物的事实或原始用户对话。示例的参考回答是作者编写的合格例子，未冒充任何系统实测结果。

示例公开后可以被训练、调试和针对性优化，所以它适合作为讲解与开发材料，不是保密考试。不能用示例上的成绩替换原来的视频成绩，也不能把它宣传成未见题泛化能力。

正式题将来若发布，应逐版冻结与记录改动，公开来源和适用范围；已经曝光的题与后续保留题分开。当前没有自动公开正式题的日程或后台发布任务。

## 如何更正

反馈应引用公开题号或配置段落，说明矛盾在哪里。确认问题后记录版本、原因和影响范围。评分标准修改需统一适用于相关系统，不为某个结果单独调整。
